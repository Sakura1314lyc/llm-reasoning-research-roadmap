# 学习笔记使用说明

这个目录记录每日学习过程和每周复盘。代码回答“怎么实现”，笔记应回答“我理解了什么、哪里还不清楚”。

## 推荐结构

```text
notes/
├── daily/
│   ├── week01-day01.md
│   └── week01-day02.md
├── weekly/
│   └── week01-summary.md
└── README.md
```

## 每日笔记模板

```markdown
# Week X Day Y

## 今日目标

## 核心概念

## 张量形状 / 数据流

## 完成的代码

## 实验结果

## 遇到的问题

## 我是怎么定位问题的

## 仍未解决的问题

## 明日计划
```

## 每周总结模板

```markdown
# Week X Summary

## 本周完成

## 最重要的三个知识点

## 完成的代码与实验

## 一个典型成功案例

## 一个典型失败案例

## 当前薄弱点

## 下周计划

## 准备向老师请教的问题
```

## 记录原则

- 用自己的话解释，不复制整段教程
- 记录失败尝试和修复过程
- 关键结论链接到对应代码、论文或实验
- 重要张量写出形状变化
- 实验数字注明配置和数据来源
- 不在笔记中记录 Token、密码或隐私数据

## 每周检查

- [ ] 每个学习日都有简短记录
- [ ] 本周代码可以重新运行
- [ ] 至少总结一个错误案例
- [ ] 未解决问题进入下周计划
- [ ] 重要内容已经链接到对应目录
